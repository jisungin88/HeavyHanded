# 08. 외부 플러그인 및 에셋 연동

> 이 문서는 **커밋되어 확인 가능한 설정**을 기준으로 쓴다.
>
> 짧지만 단독 문서로 둔다. **"도입하지 않기로 한 결정"이 기록될 곳이 여기뿐이기 때문이다.**
> 코드에는 쓴 것만 남고 안 쓴 것은 안 남는다. 기록이 없으면 같은 논의가 반복된다.

## 2. 활성 플러그인

`HeavyHanded.uproject` 기준. **전부 엔진 내장 플러그인이고, 서드파티는 하나도 없다.**

| 플러그인 | 대상 | 쓰는 곳 |
|---|---|---|
| `GameplayAbilities` | Runtime | 역할별 스킬, 쿨다운, 상태 태그, GameplayCue |
| `OnlineSubsystem` | Runtime | 세션 인터페이스 |
| `OnlineSubsystemNull` | Runtime | LAN + 직접 IP 접속 |
| `Niagara` | Runtime | 스킬 · 파손 연출 |
| `ModelingToolsEditorMode` | **Editor 전용** | 에디터 메시 편집 |

### 에디터 전용 플러그인은 `TargetAllowList` 로 막는다

```json
{
    "Name": "ModelingToolsEditorMode",
    "Enabled": true,
    "TargetAllowList": [ "Editor" ]
}
```

이게 없으면 **런타임 빌드에도 플러그인이 딸려 들어간다.** 패키지 용량이 늘고,
쿠킹 시간이 늘고, 최악의 경우 런타임에 없어야 할 모듈이 로드된다.
**에디터에서만 쓰는 플러그인을 켤 때는 반드시 이 항목을 같이 넣는다.**

## 3. 도입하지 않기로 한 것

**여기 있는 것을 다시 제안하기 전에, 결정 이유가 아직 유효한지 먼저 확인한다.**
유효하지 않게 됐다면 도입하되, **왜 사라졌는지 이 표에 적는다.**

| 대상 | 결정 | 이유 | 재검토 조건 |
|---|---|---|---|
| **CommonUI** | 미도입 | UMG 단독으로 간다 | 게임패드 · 포커스 관리가 실제 문제가 됐을 때 |
| **Chaos Geometry Collection** | 미도입 | 파손 연출은 **메시 스왑 + Niagara** 로 만든다 | 파손 연출 품질이 부족하다고 판단됐을 때 |
| **`bEnablePhysicsPrediction`** | 미사용 | Resimulation 전용 히스토리 캐시다. `PredictiveInterpolation` 에는 불필요하고, **엔진 주석상 resim 을 쓰지 않을 때도 물리 해석에 영향을 준다** | 물리 복제 모드를 바꿀 때 |
| **`OnlineSubsystemSteam`** | 추후 | 지금은 `Null` 로 LAN + 직접 IP. 개발 중에는 Steam 클라이언트 의존이 없는 편이 빠르다 | 외부 배포가 필요해졌을 때 |
| **LFS 파일 락 (`lockable`)** | 보류 | 락을 모르는 팀원이 "저장이 안 돼요" 상태에 빠지는 비용이 크다 | 공지로 막지 못한 에셋 충돌 사고가 실제로 났을 때 ([06](06-Collaboration.md) 5장) |

각 결정의 상세 근거는 — 물리 쪽은 `Config/DefaultEngine.ini` 의 `[/Script/Engine.PhysicsSettings]` 주석,
세션 쪽은 [02-Networking.md](02-Networking.md) 2장.

### 세션 현황

**현재 `OnlineSubsystemNull` 이다.** LAN 과 직접 IP 접속만 된다.
Steam 전환은 결정만 되어 있고 착수하지 않았다.

## 4. 외부 에셋

### 현황

| 항목 | 상태 |
|---|---|
| `Plugins/` 폴더 | **없음.** 서드파티 플러그인 0개 |
| 마켓플레이스 에셋 | **없음** |
| `Content/` 최상위 | `HeavyHanded/` (우리 것), `Developers/` (개인 작업), `Collections/` (에디터 컬렉션) |

`.gitignore` 에는 서드파티 플러그인용 규칙이 미리 준비되어 있다
(`Plugins/**/Binaries/`, `Plugins/**/Build/`, `Plugins/**/Intermediate/`).
도입하면 소스만 커밋되고 빌드 산출물은 제외된다.

### 반입 규칙

1. **외부 에셋은 원래 폴더 구조를 유지한다.** `Content/HeavyHanded/` 아래로 옮기지 않는다 —
   그 폴더는 우리가 만든 것만 두는 자리다 ([05](05-Conventions.md) 10장).
   섞이면 나중에 무엇이 우리 것인지 구별할 수 없다.
2. **`.gitattributes` 의 LFS 대상인지 확인한다.** 새 확장자가 들어오면 규칙을 추가한다.
   빠뜨린 채 커밋하면 실제 바이너리가 저장소에 들어가고, 나중에 걷어내려면 히스토리 재작성이 필요하다.
3. **라이선스와 출처를 이 문서에 기록한다.** 상용 배포 시점에 확인하려면 이미 늦다.
4. 대용량 에셋은 팀에 먼저 공지한다. 전원이 다시 받아야 한다.

## 5. 플러그인 · 에셋 도입 절차

플러그인 도입은 **되돌리기 비싼 결정**이다. 한 번 코드가 의존하면 걷어내기 어렵다.

1. **팀에 먼저 제안한다.** 3장 표에 이미 "미도입"으로 적혀 있는지 확인
2. **라이선스 · 용량 · 유지보수 상태**를 확인한다
3. `HeavyHanded.uproject` 에 추가. **에디터 전용이면 `TargetAllowList` 를 같이 넣는다** (2장)
4. 필요하면 `Build.cs` 에 모듈 추가 — **어느 시스템 때문에 들어왔는지 주석으로 남긴다**
   ([01](01-Architecture.md) 2장의 형식을 따른다). 나중에 안전하게 걷어내려면 이 대응이 필요하다
5. **이 문서 2장 표에 추가한다**
6. 검토했지만 안 쓰기로 했다면 **3장 표에 이유와 함께 남긴다**

6번을 빠뜨리지 말 것. **검토한 기록이 없으면 같은 논의를 처음부터 다시 하게 된다.**

---

## 6. 이 문서를 고쳐야 할 때

- 플러그인을 켜거나 끄면 2장을 고친다
- **무언가를 검토하고 안 쓰기로 했으면 3장에 한 줄 추가한다.** 이 문서에서 가장 자주 늘어야 할 부분이다
- 3장의 항목을 도입하기로 뒤집으면, 지우지 말고 **결정이 바뀐 이유를 적은 뒤** 2장으로 옮긴다
- 외부 에셋을 반입하면 4장에 출처와 라이선스를 적는다
