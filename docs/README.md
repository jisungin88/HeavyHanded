# Sneakers — 기술설계서

기획명 **Sneakers**(가칭) / 리포지토리 **HeavyHanded**.
2~4인 온라인 협동 물리 운반 게임. Unreal Engine 5.4, Listen Server.

### 새로 합류했다면

1. **01** 전체 조감도
2. **02** 서버 권위 원칙 (이걸 모르면 어떤 코드도 못 짠다)
3. **05** 폴더 구조, 네이밍, 인코딩
4. 자기가 맡을 Systems 문서

## 코드 주석의 옛 절 번호

소스 주석에 `(컨벤션 2-2)`, `팀 컨벤션 3-1` 같은 참조가 남아 있다. 옛 번호 체계다.

| 옛 번호 | 현재 문서 |
|---|---|
| 2-1 명명 규칙 · 2-2 클래스 접두사 | 05 — 명명 규칙 |
| 2-3 UPROPERTY / UFUNCTION | 05 — 매크로 |
| 2-4 전방 선언 | 05 — 헤더 최적화 |
| 2-5 UObject 포인터 / GC | 05 — 포인터와 GC |
| 3-1 · 3-2 · 3-3 네트워크 규칙 | 02 — 서버 권위 · 복제 수단 |
| 4-1 에셋 접두사 · 4-2 폴더 규칙 | 05 — 에셋 접두사 · 폴더 구조 |
| 4-3 "로직은 C++, BP 는 값만" | 03 — 데이터는 BP, 로직은 C++ |
| 4-4 Git 작업 순서 · 커밋 메시지 | 06 — Git 작업 순서 · 커밋 규약 |

새 코드에는 절 번호를 적지 않는다. 문서 이름으로 적는다.
